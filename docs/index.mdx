## Use MCP with your agent

[Start with the MCP setup guide](/mcp/quickstart): install the server, choose
allowed folders, and connect Claude Code. Then learn how to
[scan and transform files](/mcp/scanning-and-transformations).

datafog MCP uses Core for detection. You do not need to write SDK code to use it.

## Build with the Core SDK

[Run the Core quickstart](/get-started/quickstart) to detect and redact an email
address in your runtime. For package choices, see [installation](/get-started/installation).
For the engine's capabilities and operation model, see the [Core overview](/core).

Already using the older `datafog` Python package? Follow the
[migration guide](/guides/migrating-from-datafog-python).
