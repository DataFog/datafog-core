<Note>The expanded detectors are available in **0.4.0 or newer** across all four runtimes. Runtime capability discovery is available in Rust and Python. See the [0.4.0 release notes](/releases/0-4-0).</Note>

<Note>The three credential detectors require [Core 0.4.1](/releases/0-4-1) or newer.</Note>

## Package availability

The structured PERSON APIs require version **0.3.0 or newer** in every
binding. See the [0.3.0 release notes](/releases/0-3-0).

| Runtime | Distribution | Import | Availability |
| --- | --- | --- | --- |
| Rust | `datafog-core` | `datafog_core` | Published on crates.io |
| Python | `datafog-core` | `datafog_core` | Published on PyPI |
| Node.js | `@datafog/node` | `@datafog/node` | Published on npm |
| Browser/WASM | `@datafog/wasm` | `@datafog/wasm` | Published on npm |

<CodeGroup>

```bash Rust
cargo add datafog-core
```

```bash Python
python -m pip install datafog-core
```

```bash Node.js
npm install @datafog/node
```

```bash Browser / WASM
npm install @datafog/wasm
```

</CodeGroup>

<Warning>
  Do not use `pip install datafog` when following these pages. That command
  installs the established datafog Python library, not datafog core. If you are
  moving an existing application, follow [Migrate from datafog
  Python](/guides/migrating-from-datafog-python).
</Warning>

## Runtime requirements

- Rust `1.88` or newer
- Python `3.10` or newer
- Node.js `24.x` for the native Node package
- A browser with WebAssembly support for the browser package

## Python wheel and source-build requirements

Python 1.4.0 has CPython 3.10+ ABI3 wheels for:

- Linux x64/ARM64 with glibc 2.28+ or musl 1.2+
- Linux s390x/ppc64le with glibc 2.28+
- macOS Intel 10.12+ or Apple Silicon 11+
- Windows x64/ARM64

PyPy, free-threaded CPython, older libc versions and other architectures use
the source distribution. Building it needs Rust 1.88+, Cargo, a native linker,
and access to Cargo dependencies. Rustup uses the exact toolchain shipped in
`rust-toolchain.toml`; it can download that toolchain if it is not present.
Offline installs need these prerequisites provisioned in advance.

To require a prebuilt wheel and avoid source-build prerequisites:

```bash
python -m pip install --only-binary=:all: datafog-core==1.4.0
```

The Python registry currently publishes 1.4.0; Rust and npm publish 1.1.0. Use
the versions from the [README](https://github.com/DataFog/datafog-core#quickstart)
when matching findings across runtimes.
